Cara Pasang ke Layar Utama

Aplikasi MyMoney mendukung teknologi PWA (Progressive Web App) sehingga dapat dipasang di HP layaknya file APK resmi tanpa iklan dan dapat diakses secara instan.

📱 Untuk Pengguna Android (Chrome):

  1. Buka halaman aplikasi ini menggunakan browser Google Chrome.
  2. Ketuk ikon titik tiga (⋮) di pojok kanan atas browser.
  3. Pilih menu "Tambahkan ke Layar utama" (Add to Home screen) atau "Instal aplikasi".
  4. Ketuk Tambahkan / Instal. Ikon MyMoney akan muncul di menu aplikasi HP Anda!

🍎 Untuk Pengguna iPhone (Safari):

  1. Buka halaman ini di browser Safari.
  2. Ketuk ikon Bagikan (Share) di bagian bawah layar.
  3. Gulir ke bawah dan pilih "Tambah ke Layar Utama" (Add to Home Screen).

Reset Semua Data?
